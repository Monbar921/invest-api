# INVEST-001: публичный Telegram-канал - устройство

Правила - в [business-rules.md](../../business-rules.md#публичный-telegram-канал); здесь - где что живёт и почему так.

## Данные

Таблица `channel_post` (миграция `023-telegram-channel.xml`) - очередь и история постов:

| Колонка | Что |
| ------- | --- |
| `kind` | `RATING_ACTION`, `KEY_RATE`, `WEEKLY_TOP` |
| `dedup_key` | уникален: `RATING_ACTION:<id новости>`, `KEY_RATE:<id новости>`, `WEEKLY_TOP:<ISO-год>-W<неделя>` |
| `text` | готовый текст поста |
| `status` | `PENDING` → `SENT` / `FAILED` (Telegram отклонил: 400, 403) / `SKIPPED` (не успел до `expires_at`) |
| `attempts`, `next_attempt_at`, `last_error` | повторы после сбоя связи (через 5 минут, при 429 - не раньше `retry_after`) |
| `expires_at` | время события + `max-age` (2 дня): позже пост неактуален |
| `sent_at`, `message_id` | когда и каким сообщением опубликован |

Очередь уведомлений `notification` не подошла: она на пользователя (`user_id` обязателен, отправка ищет чат в
`telegram_link`), без лимита в день и окна публикации; канал - один адресат с другими правилами отправки.

## Код

| Что | Где |
| --- | --- |
| настройки, проверка при старте | `ChannelProperties` (`ru.invest.api.telegram.channel`) |
| какое рейтинговое действие - пост | `RatingActionClassifier`: глагол действия (не «прогноз» после него) + `CreditRatingParser` (национальная шкала) |
| решение по ключевой ставке | `KeyRateDecision` (common) - общее с правилом уведомлений `KEY_RATE` |
| сбор и публикация | `ChannelUseCaseImpl` |
| тексты | `ChannelTexts` |
| сбор после загрузки ленты | `ChannelNewsListener` (`NewsSyncedEvent`) |
| расписание | `ChannelScheduler`: публикация раз в 5 минут (ShedLock `TelegramChannelPublish`), подборка по cron (`TelegramChannelWeeklyTop`), очистка в 04:30 (`TelegramChannelCleanUp`) |
| эмитенты новости при чтении | `NewsUseCaseImpl` теперь заполняет `NewsModel.emitterIds` из ссылок новости (в API не отдаётся) |

Бины канала - при включённом боте (`ru.invest.api.telegram.enabled`): нужен `TelegramClient` с прокси. Флаг канала
проверяется в каждом методе use case, а не условием бинов: так «выключен - ничего не уходит» проверяется тестом на
работающем приложении, и очередь не теряется при временном выключении.

## Как работает

1. **Сбор из ленты** - после каждой загрузки ленты (раз в 15 минут): последние 100 новостей АКРА и НКР и 100
   пресс-релизов ЦБ, опубликованных не раньше `max-age` назад, старые первыми. Подходящие - в очередь, если ключа ещё
   нет. Отдельной отметки «докуда просмотрено» нет: окно `max-age` и уникальный ключ дают то же без состояния.
2. **Подборка** - по cron: для каждой группы рейтинга из конфигурации - фильтр списка облигаций (`BondUseCase.getAllPage`
   - тот же, что у скринера): постоянный купон, рейтинг в диапазоне группы, до погашения не меньше
   `min-years-to-maturity`, оборот не меньше `min-turnover-rub`, по убыванию доходности к погашению; из первых 50 -
   рублёвые с известной положительной доходностью, первые `per-group`. Пустые группы не показываются, все пустые -
   поста нет.
3. **Публикация** - раз в 5 минут: устаревшие → `SKIPPED`; вне окна, при исчерпанном лимите дня или паузе после
   прошлого поста - ничего; иначе самый старый готовый пост, один за раз, без превью ссылок.

## Решения и отвергнутые варианты

- **Только изменения рейтинга.** АКРА и НКР публикуют десятки подтверждений в день; при лимите 5 постов они вытеснили
  бы изменения. Подтверждение и прогноз не меняют рейтинг.
- **Только эмитенты из системы.** Пост без страницы продукта не решает задачу канала; новость привязана к эмитенту тем
  же `IssuerMatcher`, что вкладка «Новости».
- **Флоатеры по ссылке поста о ставке** - ссылка на подборку по факту (у флоатеров купон обычно привязан к ставке),
  без вывода «что покупать».
- **Подборка по доходности к погашению, без флоатеров** - у флоатера доходность считается по текущему купону и с
  фиксированными несравнима. Валютные выпуски не смешиваются с рублёвыми.
- **Отдельный бот канала** отвергнут: ещё один токен и прокси ради публикации; администратором канала можно сделать
  того же бота.
