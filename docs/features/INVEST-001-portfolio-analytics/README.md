# INVEST-001: Аналитика портфеля

Статус: **в работе** - сделано 2026-11-15, этап 12 [дорожной карты](../../roadmap.md). Код не закоммичен; ветки - те,
на которых сейчас репозитории: invest-api `feature/INVEST-001`, invest-api-ui `feature/INV-001` (отдельную ветку
называет владелец). Gateway не меняется: `/api/portfolio/**` уже проксируется.

## Цель

Пользователь видит структуру и риск своего портфеля: в чём он сосредоточен и как его стоимость ответит на
изменение ставок.

## Объём

- **invest-api** - модуль `feature/portfolio-service`, `GET /portfolio/analytics`:
  - доли открытых позиций по эмитентам, секторам, рейтингам, валютам номинала и типу купона; лестница погашений
    по годам; вес позиции - текущая стоимость в рублях без НКД, как в портфеле;
  - средневзвешенные доходность к погашению и дюрация (Маколея, модифицированная) с долей стоимости, по которой
    они посчитаны;
  - концентрация - крупнейший эмитент и его доля;
  - чувствительность к ставке: изменение стоимости при сдвиге доходности на ±1 п.п. через модифицированную
    дюрацию, без флоатеров.
- **invest-api-ui** - вкладка «Аналитика» на странице портфеля (`/portfolio?tab=analytics`, `PortfolioAnalytics`):
  карточки итогов, доли полосками по каждому разрезу, столбики лестницы погашений, предупреждение об облигациях
  без оценки.

## Готово, когда

- [x] доли каждого разреза в сумме дают 100 % - округление методом наибольшего остатка,
  `PortfolioAnalyticsCalculatorTest.sharesAlwaysSumToHundred` и проверка суммы в `PortfolioAnalyticsTest`;
- [x] позиции без данных вынесены в «нет данных», а не пропадают: без признака - группа `key = null` в каждом
  разрезе, без оценки в рублях (нет цены, курса, облигации нет в системе) - список `unvalued` с причиной и
  предупреждение в UI;
- [ ] вкладка проверена в браузере на стенде с бэком и входом через Keycloak (тесты UI - на моках `fetch`).
