# INVEST-001: данные для скринера

Статус: **в работе** - сделано 2026-11-14, этап 10 [дорожной карты](../../roadmap.md). Код не закоммичен; ветки - те,
на которых сейчас репозитории: invest-api `feature/INVEST-001`, invest-api-ui и invest-gateway - текущие (отдельную
ветку называет владелец). Проверить в браузере на стенде с бэком: в этом изменении UI проверен тестами и вёрсткой
фильтров на dev-сервере без бэка.

## Цель

Фильтры и сортировки, которых ждут держатели облигаций: кредитный рейтинг, дюрация, ликвидность, спред к ОФЗ, база
флоатера, а также сектор, срок до погашения, частота купона, оферта и амортизация; выгрузка выборки в Excel / CSV.

## Объём

- **invest-api**
  - **Кредитный рейтинг** эмитента и выпуска: из заголовков релизов АКРА и НКР, которые уже грузит лента, -
    таблица `credit_rating` (текущий рейтинг по агентству и эмитенту / ISIN, отзыв, прогноз, дата, ссылка на релиз).
    Общая шкала двух агентств (`RatingScale`, D = 0 ... AAA = 20); у облигации - самый низкий из агентств.
    При первом запуске - история релизов за 15 месяцев (АКРА по страницам, НКР целиком), потом - из каждой
    загрузки ленты; maintenance-эндпоинт перечитывает историю.
  - **Дюрация** Маколея и модифицированная к погашению - в том же расчёте, что доходность к погашению (`coupon`).
  - **Ликвидность** - средний дневной объём и оборот по свечам за 30 дней (считается при загрузке кэша облигаций).
  - **Спред к ОФЗ** - доходность к погашению минус кривая бескупонной доходности Мосбиржи (КБД) на срок дюрации;
    кривая считается по параметрам биржи (формула сверена с её опубликованными точками), кэш - час.
  - **База флоатера** - `COUPON_DETAILS` Мосбиржи («Ключевая ставка», «Ставка RUONIA»), таблица `bond_coupon_base`;
    **премия - `null`**: бесплатного источника нет (ISS её не отдаёт).
  - Фильтры `BondParametersRequest`: `sectors`, `yearsToMaturity`, `couponFrequencies`, `hasOffer`, `hasAmortization`,
    `creditRating`, `duration`, `yieldToMaturity`, `avgDailyTurnover`, `spreadToOfz`; сортировки `DURATION`,
    `CREDIT_RATING`, `AVG_DAILY_TURNOVER`, `SPREAD_TO_OFZ` - `null` в конце.
  - `POST /bonds/{all|local|foreign}/export?format=CSV|XLSX` - вся выборка файлом; `GET /bonds/sectors`.
- **invest-gateway** - без изменений маршрутов: выгрузка намеренно только после входа (новый POST под `/api/bonds` не
  публичен); тест это закрепляет.
- **invest-api-ui** - колонки «Рейтинг», «Дюрация», «Спред к ОФЗ», «Оборот в день» с сортировкой; панель «Ещё
  фильтры» (рейтинг, доходность, спред, дюрация, срок, оборот, сектор, частота купона, оферта, амортизация) - в URL;
  кнопка «Выгрузить» (Excel / CSV), у гостя - «Войти, чтобы выгрузить»; в карточке - рейтинги агентств со ссылками на
  релизы, дюрация, спред, оборот, база флоатера. Цель аналитики `bond_export`.

## Ограничения

- Рейтинги - только АКРА и НКР: Эксперт РА (крупнейшее агентство) и НРА списков релизов без скрипта не отдают.
  У облигации без рейтинга этих агентств рейтинга нет, а не «низкий».
- Рейтинг выпуска НКР без ISIN находится по номеру серии в названии облигации T-Invest - если серия записана иначе,
  выпуск получит рейтинг эмитента.
- Премия флоатера всегда `null`.
