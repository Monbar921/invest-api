# INVEST-001: Аналитика и лендинг

Статус: **в работе** - сделано 2026-11-12, этап 4 [дорожной карты](../../roadmap.md). Код не закоммичен; меняются invest-api-ui
(ветка `feature/INV-001`) и realm Keycloak в invest-deploy (`feature/INV-001`); отдельную ветку называет владелец.

> Счётчик Метрики в сборке не задан (`VITE_YANDEX_METRIKA_ID`), поэтому аналитика выключена и баннера согласия нет.
> Включать: завести счётчик и цели (ниже), собрать UI с номером счётчика. Перед этим - политика обработки персональных
> данных (решение владельца 0.5): Метрика ставит cookie.
>
> Саморегистрация в Keycloak включена в `invest-deploy/keycloak/invest-realm.json` (`registrationAllowed: true`) -
> «Войти / Зарегистрироваться» ведёт на форму входа со ссылкой «Регистрация». На стенде, где realm уже импортирован,
> её включают в админке ([invest-deploy/docs/deployment.md](../../../../invest-deploy/docs/deployment.md)).

## Цель

Видеть, какими фичами пользуются, и объяснять продукт новому посетителю.

## Объём

- **invest-api-ui** - продуктовая аналитика (`lib/analytics.ts`):
  - сервис - Яндекс Метрика, номер счётчика из сборки; не задан - модуль ничего не делает;
  - просмотры страниц SPA на каждую смену маршрута (путь и query), с прошлой страницей в referer;
  - цели - ключевые действия (таблица ниже), только тип действия, без персональных данных;
  - баннер согласия (`AnalyticsConsent`): счётчик грузится только после «Принять», до согласия и после отказа события
    отбрасываются; выбор хранится в `localStorage`;
  - Вебвизор и карта кликов выключены.
- **invest-api-ui** - лендинг на `/` для гостя (`HomePage` → `LandingPage`): что умеет продукт (шесть возможностей,
  личные - с пометкой «после входа»), «Войти / Зарегистрироваться» и «Смотреть облигации», первые облигации первой
  подборки на настоящих данных, оговорка «только информирует». Вошедшего `/` ведёт на `/bonds`, как раньше.

### Цели

В Метрике заводятся как «JavaScript-событие» с этими идентификаторами.

| Цель                       | Когда                                                               | Параметры                            |
| -------------------------- | ------------------------------------------------------------------- | ------------------------------------ |
| `bond_filter`              | изменён фильтр списка облигаций                                     | `filter` - имена полей, без значений |
| `profit_calculation`       | калькулятор посчитал доход - раз на открытую облигацию              | -                                    |
| `portfolio_position_added` | в портфель добавлена покупка                                        | -                                    |
| `alert_rule_created`       | создано правило уведомлений (включение выключенного не считается)   | `type` - тип правила                 |
| `telegram_connected`       | бот подтвердил привязку, пока панель ждала «Старт»                  | -                                    |
| `landing_login`            | «Войти / Зарегистрироваться» на лендинге                            | -                                    |

## Готово, когда

- [x] события видны в выбранном сервисе - проверено тестами на вызовах счётчика (`lib/analytics.test.ts`: запуск после
  согласия без Вебвизора, просмотры с referer, цели, ничего без счётчика, до согласия и после отказа; цели - в тестах
  фильтра, калькулятора, портфеля, уведомлений и Telegram). **В настоящей Метрике не проверено**: счётчика ещё нет;
- [x] гость на `/` видит лендинг, вошедший - список облигаций - `pages/landing.test.tsx`; в браузере на dev-сервере
  (без gateway) лендинг гостя открывается.

Вместо скриншотов на лендинге - живые данные подборки: не устаревают с каждым изменением интерфейса. Статичные
картинки можно добавить позже, когда будет стенд с данными для съёмки.
