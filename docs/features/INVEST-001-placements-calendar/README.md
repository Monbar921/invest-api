# INVEST-001: календарь размещений

Статус: **остановлен** 2026-11-15 после исследования - этап 14 [дорожной карты](../../roadmap.md). Надёжного
бесплатного источника данных о предстоящих размещениях без ключа не нашлось; по правилу этапа он не делается на
ненадёжных данных. Код не менялся. Подробности и варианты продолжения - в [design.md](design.md).

## Цель

Раздел о новых выпусках облигаций, которых ещё нет в торгах: эмитент, ориентир купона, срок, дата сбора заявок,
рейтинг; уведомление «новое размещение»; публичная страница «Размещения».

## Что сделано

- Исследование источников (Мосбиржа ISS, T-Invest API, Cbonds, сайты-агрегаторы) - [design.md](design.md).

## Что не сделано

- api: загрузка и хранение размещений, связь с облигацией, правило уведомления «новое размещение».
- ui: страница «Размещения».

## Что нужно, чтобы продолжить

Решение владельца (как этап 0) - одно из:

1. **Платный или договорной источник** - Cbonds (поля размещения есть в `get_emissions`, доступ по регистрации и
   оферте) или другой поставщик. Тогда этап делается целиком, источник - за интерфейсом, ключ - в конфигурации.
2. **Урезанный этап на T-Invest API** - если проверка (см. design.md, «Что не проверено») покажет, что
   `Bonds` со статусом `INSTRUMENT_STATUS_ALL` отдаёт выпуски до начала торгов. Будут только эмитент, номинал, срок,
   дата размещения и, если объявлен, купон; ориентира купона и даты сбора заявок не будет.
3. **Отказаться от этапа** или отложить; этап 15 (Telegram-канал) от него зависит только «желательно».
