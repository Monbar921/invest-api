# INVEST-001: лента новостей и события облигации

Статус: **в работе**. Ветка `feature/INVEST-001` (та же, что у доходностей, калькулятора и графика цены).

## Цель

На главной (слева от таблицы облигаций) - лента финансовых новостей: ставка ЦБ, курсы, новости Банка России и
Мосбиржи. В карточке облигации - то же по конкретной бумаге, причём события из данных облигации отделены от внешних
новостей.

## Решения пользователя (2026-11-05)

- Только бесплатные источники.
- События из данных облигации нужны, но отдельно от внешних новостей.
- Работа в той же ветке `feature/INVEST-001`.

## Объём

- Бэк: модуль `news-supplier`, таблицы `news`, `news_link`, `bond_issuer`; загрузка раз в 15 минут; эндпоинты
  `/bonds/news`, `/bonds/{ticker}/news`, `/bonds/market-overview`, `/bonds/{ticker}/events`; maintenance
  `/maintenance/news/sync-all`.
- UI: панель слева на `/bonds` (ставка, курсы, лента с фильтром «Все / Банк России / Мосбиржа»); в карточке вкладки
  «События по бумаге» и «Новости».

Второй этап (2026-11-05, «прикрутим все остальные источники, чтобы поиск по бумаге работал»): рейтинговые
агентства АКРА и НКР, RSS СМИ (Интерфакс, РБК, Коммерсантъ, Ведомости, Финам, Frank Media, Smart-Lab), поиск
эмитента без кавычек. UI: фильтр «Все / ЦБ / Биржа / Рейтинги / СМИ».

Правила - [business-rules.md](../../business-rules.md#лента-новостей), устройство - [design.md](design.md).

## Открытые вопросы

- Эксперт РА (список релизов грузится скриптом) и НРА (списка нет) - не подключены.
- Раскрытие эмитентов (e-disclosure) недоступно автоматически (403).
- Падежи в названиях эмитентов не учитываются - часть новостей СМИ и НКР («Альфа-Банку») не привязывается.
