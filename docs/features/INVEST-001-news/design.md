# INVEST-001: лента новостей - устройство

## Источники (проверены 2026-11-05)

| Источник | Запрос | Что |
| --- | --- | --- |
| ЦБ, пресс-релизы | `GET https://www.cbr.ru/rss/RssPress` | RSS 2.0, UTF-8 с BOM, описание - HTML, ~13 записей |
| ЦБ, события | `GET https://www.cbr.ru/rss/eventrss` | RSS 2.0, без описаний, ~100 записей |
| ЦБ, ключевая ставка | `POST https://www.cbr.ru/DailyInfoWebServ/DailyInfo.asmx`, SOAPAction `KeyRateXML` | ставка по рабочим дням |
| Мосбиржа, новости | `GET https://iss.moex.com/iss/sitenews.json?start=` | по 50, новые первыми; текст - `/iss/sitenews/{id}.json` |
| Мосбиржа, эмитенты | `GET https://iss.moex.com/iss/securities.json?engine=stock&market=bonds&is_trading=1&start=` | по 100, `emitent_id`, `emitent_title`, `emitent_inn`; ~3200 выпусков |
| e-disclosure | - | 403 на автоматические запросы, не используем |

Ответы ЦБ клиент получает байтами (`byte[]`), XML разбирает `DocumentBuilder` без DTD и внешних сущностей: так
кодировку и BOM обрабатывает парсер, а не конвертер строк Spring. Параметры ISS передаются картой (`@RequestParam Map`).

## Модули и классы

| Класс | Что |
| --- | --- |
| `cb-rf-supplier` `CbRfNewsUseCaseImpl` | RSS ЦБ → `NewsModel`, ключевая ставка; упавшая лента пропускается |
| `news-supplier` `MoexNewsUseCaseImpl` | новости Мосбиржи новее известной, фильтр шума, ISIN из заголовка и текста; эмитенты выпусков |
| `NewsSyncUseCaseImpl` | шаги загрузки, привязка к эмитентам по названию в кавычках и по ISIN, дедупликация по `(source, external_id)`, очистка |
| `NewsUseCaseImpl` | лента и новости облигации, страницы; облигации и эмитенты новости подгружаются одним запросом на страницу |
| `MarketOverviewUseCaseImpl` | ставка и курсы, кэш `MARKET_OVERVIEW` 30 минут |
| `NewsSyncScheduler`, `NewsSyncStartupRunner` | расписание и запуск при старте в фоне |
| `common` `BondEventUseCaseImpl` | события облигации - чистая функция от карточки и графика амортизации |
| `ui-service` `NewsController`, `NewsMaintenanceController`, `BondController.getEvents` | REST |

Пути новостей - под `/internal/rest/bonds`, потому что gateway пропускает наружу только `/api/bonds/**`; литеральные
`/bonds/news` и `/bonds/market-overview` Spring предпочитает шаблону `/bonds/{ticker}`.

## Решения и отвергнутые варианты

- **Эмитент - из Мосбиржи, а не из T-Invest**: ISS отдаёт эмитента и ИНН всех облигаций списком за ~30 запросов,
  у T-Invest пришлось бы запрашивать по облигации. Связь `bond_issuer` с облигацией - по ISIN без внешнего ключа:
  облигации пересоздаются синхронизацией, а эмитенты обновляются раз в сутки.
- **Поиск эмитента в тексте - только в кавычках**: без них ложные совпадения у коротких названий. Пропуски
  (эмитенты без кавычек, другое написание) приняты: ISIN всё равно связывает новость с выпуском.
- **Текст новостей не храним**: только заголовок, анонс и ссылку. Текст Мосбиржи грузится один раз при загрузке -
  для поиска ISIN и названий.
- **События облигации не храним**: считаются при запросе из графиков, которые уже есть в БД.
- **Ставка и курсы не храним**: нужны только текущие значения и прошлое для изменения, ЦБ отдаёт историю сам.
- **На первой загрузке - 4 страницы Мосбиржи** (~3 дня после фильтра): глубже история для ленты не нужна, а
  каждая новость - ещё запрос за текстом.

## Проверено на живых источниках

Временным тестом против настоящих ЦБ и ISS (2026-11-05): 113 новостей ЦБ с анонсами, ставка 14,00% с 27.07.2026
(прошлая 14,25%), курсы USD/EUR/CNY с изменением, 67 новостей Мосбиржи после фильтра с найденными ISIN, 3187
выпусков с эмитентами. По итогам в фильтр добавлены «риск-параметры» и «пересмотр баз расчёта индексов».
