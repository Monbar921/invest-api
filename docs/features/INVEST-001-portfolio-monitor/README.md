# INVEST-001: монитор риска и дайджест портфеля в Telegram

Статус: **в работе** - сделано 2026-11-15, этап 13 [дорожной карты](../../roadmap.md). Код не закоммичен; ветки - те,
на которых сейчас репозитории: invest-api `feature/INVEST-001`, invest-api-ui `feature/INV-001` (отдельную ветку
называет владелец). Проверено тестами (бэк - Testcontainers, UI - Vitest) и на стенде k3d 2026-11-15; найденная там
ошибка исправлена (см. ниже).

## Цель

Пользователь узнаёт о проблемах эмитентов своих облигаций и возвращается в продукт - не настраивая уведомления по
каждой облигации.

## Объём

- **invest-api** - модуль `feature/alert-service`, два новых типа правил уведомлений без облигации, по одному на
  пользователя, через существующие `POST /alerts`, очередь `notification` и Telegram:
  - `PORTFOLIO_RISK` - монитор риска по всем открытым позициям портфеля: понижение рейтинга (АКРА, НКР), приостановка
    торгов (Мосбиржа), дефолт и технический дефолт (любой источник). Источник - новости, уже привязанные к выпускам и
    эмитентам; проверка после каждой загрузки ленты.
  - `PORTFOLIO_DIGEST` с `days` 1 или 7 - дайджест раз в день или раз в неделю (в понедельник): стоимость портфеля и
    её изменение с прошлого дайджеста, выплаты периода из календаря выплат, новости по облигациям портфеля.
- **invest-gateway** - без изменений: `/api/alerts/**` уже проксируется.
- **invest-api-ui** - карточка «Портфель» на странице «Уведомления»: переключатель монитора риска, переключатель
  дайджеста и выбор периода (раз в день / раз в неделю).

## Готово, когда

- [x] одно событие - одно уведомление на пользователя, даже если у него несколько выпусков эмитента: выпуски одного
  эмитента - одно сообщение (`PortfolioMonitorTest.oneEventIsOneNotificationForSeveralIssuesOfEmitter`); то же событие
  из других источников (биржа, агентство, СМИ) в пределах 3 дней не повторяется
  (`sameEventFromOtherSourcesIsNotRepeated`);
- [x] пустой дайджест не отправляется: пустой портфель, а также день без изменения стоимости, выплат и новостей
  (`emptyPortfolioDigestIsNotSent`, `dailyDigestValueChangeAndEmptyDays`, `digestListsNewsOfPortfolioBonds`);
- [x] приостановка торгов другим выпуском того же эмитента не тревожит (`tradingSuspensionOfOtherIssueIsIgnored`);
  заголовки разбираются на настоящих формулировках агентств, биржи и СМИ (`RiskEventClassifierTest`);
- [x] UI: включение монитора, дайджест с выбранным периодом, смена периода у включённого
  (`portfolioMonitor.test.tsx`);
- [x] на стенде k3d (2026-11-15): миграция, API (`201` / `422`), монитор на портфеле investor (три выпуска СИБУР -
  одно сообщение, доставлено в бот), повтор из другого источника на следующий день и приостановка другого выпуска -
  без уведомлений; дайджест по расписанию (стоимость, изменение, «состав менялся», выплаты недели, новости, повтор в
  тот же день и пустой - не отправляются); карточка «Портфель» в UI, ширина 375 px. `/list` в боте не проверялся.
- [x] исправлено после стенда: у только что созданного дайджеста не ставилась отметка новостей (`AlertUseCaseImpl.create`
  отправлял `PORTFOLIO_DIGEST` в ветку `days`, мимо `startFromNow`) - первый дайджест был без новостей
  (`PortfolioMonitorTest.firstDigestHasNewsSinceCreation`); суммы выплат в дайджесте - с копейками, как итог
  («152,10 ₽», а не «152,1 ₽»). На стенде исправление ещё не проверено.

## Ограничения

- Риск распознаётся только по заголовку новости (текст не хранится): «дефолт» в аналитической статье СМИ, где упомянут
  эмитент в кавычках, тоже даст уведомление. Источник в сообщении указан - пользователь видит, откуда оно.
- Эксперт РА и НРА не подключены к ленте - их рейтинговые действия монитор не видит; e-disclosure (официальные
  сообщения о неисполнении обязательств) недоступен автоматически (`403`).
- Монитор видит только облигации, которые есть в системе (по ISIN); позиция по облигации, пропавшей из T-Invest API,
  не проверяется.
- Дайджест в день, когда приложение не работало в 10:00 МСК, пропускается; следующий сравнивает стоимость с последним
  отправленным.
- Монитор и дайджест занимают место в лимите правил тарифа (`ALERTS`), как правило по ключевой ставке.
- На стенде релизы АКРА не загружаются (ошибка сертификата PKIX у источника, не этой фичи) - понижение рейтинга АКРА
  монитор там не увидит.
