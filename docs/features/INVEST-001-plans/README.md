# INVEST-001: Тарифы и права

Статус: **в работе** - сделано 2026-11-12, этап 6 [дорожной карты](../../roadmap.md). Код не закоммичен; ветки - те,
на которых сейчас репозитории: invest-api `feature/INVEST-001`, invest-gateway `test`, invest-api-ui `feature/INV-001`
(отдельную ветку называет владелец).

## Цель

Система различает бесплатного и платного пользователя (пока без оплаты - её добавит этап 7): у тарифа свои лимиты и
фичи, тариф выдаётся и отзывается вручную.

## Объём

- **invest-api** - новый модуль `feature/account-service`:
  - тарифы в конфигурации `ru.invest.api.plans`: название, платный ли, лимиты (`ALERTS` - правила уведомлений,
    `PORTFOLIO_POSITIONS` - покупки в портфеле) и фичи (`CALENDAR_ICS` - подписка на календарь выплат), тариф по
    умолчанию; ошибка в настройке не даёт приложению стартовать;
  - таблица подписок `account_subscription` (пользователь, тариф, источник, с какого момента и по какой, отзыв);
  - сервис прав `EntitlementUseCase` (интерфейс в `common`): прежние лимиты 50 правил и 200 покупок переведены на
    него, превышение - `402` с понятным описанием по-русски; подписка на календарь (`.ics`) проверяется при
    создании ссылки и при каждом запросе календаря по ней;
  - `GET /account/plan` - тариф, срок, лимиты с использованием и все тарифы для сравнения;
  - maintenance `GET` / `PUT` / `DELETE /maintenance/account/{userId}/plan` - посмотреть, выдать, отозвать.
- **invest-gateway** - маршрут `/api/account/**` → `/internal/rest/account/**` (только с сессией); `robots.txt`
  закрывает `/plan` и `/api/account`.
- **invest-api-ui** - страница «Тариф» (`/plan`, кнопка с короной в шапке): действующий тариф, срок, использование
  лимитов, сравнение тарифов; у ошибки `402` при создании правила, покупки и ссылки календаря - ссылка «Тарифы»;
  у закрытой подписки на календарь - «Доступно в платном тарифе» вместо кнопки.

## Готово, когда

- [x] смена тарифа через maintenance-эндпоинт сразу меняет лимиты - `PlanTest.grantAndRevokeChangeLimitsImmediately`;
- [x] по истечении срока пользователь на бесплатном тарифе - `PlanTest.expiredSubscriptionReturnsToDefaultPlan`
  (срок проверяется при каждом запросе, шедулер не нужен);
- [x] данные сверх лимита не удаляются, но новые не создаются (`402`) - там же; закрытая фича - `featureOutsidePlanIsClosed`;
- [ ] состав и цены тарифов - решение владельца 0.4 ([roadmap](../../roadmap.md#этап-0-решения-владельца-не-для-агента)):
  в `config/application.yml` заготовка - бесплатный повторяет прежние лимиты, «Премиум» - условные 500 правил и
  2000 покупок, подписка на календарь в обоих.

Правила - в [business-rules.md](../../business-rules.md#тарифы-и-права), как сделано - в [design.md](design.md).
