# INVEST-001: калькулятор дохода - как сделано

## Бэкенд

| Слой                        | Класс                                                                                     |
| --------------------------- | ----------------------------------------------------------------------------------------- |
| REST (`feature/ui-service`)  | `BondController.search`, `BondController.calculateProfit`; маппинг - `BondDtoMapper`          |
| use case (`bond-supplier`)   | `BondUseCase.search` (облигации из кэша), `BondUseCase.calculateProfit`                      |
| поиск (`common`)             | `BondSearchUseCaseImpl` - чистая функция над списком, ранжирование совпадений                |
| расчёт (`tinkoff-supplier`)  | `ProfitCalculationServiceImpl` - без обращений к БД и API, вход - `BondModel`                 |
| DTO (`invest-api-dto`)       | `BondSearchItemDto`, `calculation/ProfitCalculationRequest`, `ProfitCalculationDto`, `ExitTypeDto` |
| клиент (стартер)             | `InvestApiBondClient.search`, `calculateProfit`                                              |

`BondUseCase.calculateProfit` берёт карточку облигации (`findDetailedByTicker` - с графиком купонов) и добирает
будущие погашения номинала из `amortization` (`TinkoffAmortizationUseCase.findByUids`): карточка их не грузит.

Поиск идёт по кэшу облигаций (`TinkoffBondCacheRepositoryUseCase.getBonds`) - тот же набор, что и в списках, без
запроса в БД на каждую букву.

Ошибки параметров - `GeneralUnprocessableEntityException` с новым кодом `INVALID_CALCULATION_PARAMETERS` → `422`.

### Решения

- **Расчёт в деньгах, а не через ставку.** В отличие от YTM считаем простую сумму денежных потоков за период: это то,
  что пользователь проверяет руками. Годовой процент - без сложного процента (`× 365 / дней`).
- **НКД на будущую дату считаем сами** по графику купонов: из T-Invest у нас есть только НКД на сегодня
  (`aci_value` облигации). `GetAccruedInterests` не пробовали - лишний запрос к API на каждый расчёт. Начало первого
  купонного периода не хранится - берём «дата купона минус период».
- **Неполные данные не ошибка.** Необъявленные купоны, неизвестный НКД, отсутствующий график амортизации - флаги в
  ответе, UI показывает предупреждение. Иначе флоатеры нельзя было бы посчитать совсем.
- **Покупка только с сегодняшнего дня.** Для прошлых дат нет ни цены, ни номинала до прошлых погашений.

## UI

| Файл                              | Что                                                                              |
| --------------------------------- | -------------------------------------------------------------------------------- |
| `pages/CalculatorPage.tsx`        | страница `/calculator?ticker=`: поиск, показатели облигации, форма и результат     |
| `components/BondSearch.tsx`       | `Select` с подсказками с бэка: запрос после паузы 300 мс, от 2 символов            |
| `components/ProfitCalculator.tsx` | форма (количество, даты, цены, НДФЛ вкл./выкл. и ставка 13/15%, ставка вклада - по умолчанию ключевая из `useMarketOverview`) с проверкой на клиенте и результат; пересчёт после паузы 400 мс |
| `layout/AppLayout.tsx`            | пункт «Калькулятор» в шапке                                                       |
| `pages/BondPage.tsx`              | кнопка «Рассчитать доход», сектор                                                 |

Тикер выбранной облигации - в URL, форма - в состоянии компонента (с ключом по тикеру: другая облигация начинает с
своей цены и дат). Даты - `<input type="date">`: пакета `@mantine/dates` в проекте нет.

## Тесты

- `ProfitCalculationTest` - ручной пример пользователя (3,50% за 49 дней), НКД и налог 13%, ставка 15%, расчёт без
  налога, вклад с налогом и без, без ставки вклада, убыток без налога, продажа раньше погашения,
  покупка в будущую дату, оферта, амортизация до погашения и с продажей, необъявленные купоны, проверки параметров.
- `BondControllerTest` - поиск (префикс тикера, точный тикер, слова названия, ISIN, короткий запрос, limit), расчёт
  через REST, 422 и 404.
- UI `pages/calculator.test.tsx` - поиск с паузой и выбор, показатели и результат, ошибка периода без запроса,
  цена продажи раньше погашения, ссылка из карточки.
