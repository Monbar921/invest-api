# INVEST-001: калькулятор дохода

**Статус:** в работе. Ветка `feature/INVEST-001` (invest-api) и `feature/INV-001` (invest-api-ui), отдельной ветки
нет: калькулятор опирается на данные и расчёты [INVEST-001-bond-yield](../INVEST-001-bond-yield/).

## Цель

Доходность к погашению - годовая ставка и отвечает на вопрос «насколько выгодна облигация». Пользователю нужно и
другое: сколько денег и процентов он получит, если купит в одну дату и продаст в другую, после налога.

## Что входит

- Поиск облигации по мере ввода: `GET /bonds/search` - нестрогий, по тикеру, ISIN и названию.
- Расчёт: `POST /bonds/{ticker}/calculation` - покупка с НКД, купоны и частичные погашения за период, продажа по цене
  пользователя, выкуп по оферте или погашение, НДФЛ по выбору (13% или 15%), количество облигаций.
- `BondDto.sector` - сектор в карточке и калькуляторе.
- UI: страница `/calculator` (пункт «Калькулятор» в шапке рядом с «Облигации»), кнопка «Рассчитать доход» в карточке
  облигации открывает калькулятор с этой облигацией.

Решения пользователя (2026-11-04): цену продажи раньше погашения задаёт пользователь, по умолчанию - текущая;
в расчёте - количество облигаций и НДФЛ: опционально, ставку (13 или 15%) выбирает пользователь; комиссия брокера и реинвестирование купонов не учитываются.

Правила - в [business-rules.md](../../business-rules.md#калькулятор-дохода), как сделано - в [design.md](design.md).
