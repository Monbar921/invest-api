# INVEST-001: график цены облигации

**Статус:** в работе. Ветки `feature/INVEST-001` (invest-api) и `feature/INV-001` (invest-api-ui).

## Цель

Видеть, как менялась цена облигации: график в карточке, как в приложении брокера.

## Что входит

- Дневные свечи из T-Invest API (`GetCandles`) в новой таблице `price_candle`: первый раз - вся история,
  дальше ночной шаг `candle` добирает свежие.
- `GET /bonds/{ticker}/candles?interval=DAY|WEEK|MONTH&from=&to=` - свечи в % от номинала; неделя и месяц
  собираются из дневных.
- Ручной запуск: `/internal/rest/maintenance/bond/candle/{sync-all, sync-by-ticker/{ticker}}`.
- UI: график в карточке облигации - интервалы «Д / Н / Мес», периоды «1М / 6М / 1Г / 3Г / Всё», последняя цена
  и изменение за период.
- Попутно: неверный параметр запроса (дата не YYYY-MM-DD, неизвестный интервал) - `400`, а не `500`.

Решение пользователя (2026-11-04): только дневные свечи; внутридневные (5 минут и т.п.) не нужны.

Правила - в [business-rules.md](../../business-rules.md#график-цены), как сделано - в [design.md](design.md).
