# INVEST-001: Календарь выплат

Статус: **в работе** - сделано 2026-11-12, этап 5 [дорожной карты](../../roadmap.md). Код не закоммичен; ветки - те,
на которых сейчас репозитории: invest-api `feature/INVEST-001`, invest-gateway `test`, invest-api-ui `feature/INV-001`
(отдельную ветку называет владелец).

## Цель

Пользователь видит, когда и сколько денег придёт по его портфелю, и может подписаться на эти выплаты в своём
календаре (Google, Apple, Outlook).

## Объём

- **invest-api** - модуль `feature/portfolio-service`:
  - `GET /portfolio/calendar?from=&to=` - будущие купоны, амортизация, оферты и погашения по облигациям портфеля:
    события считает тот же `BondEventUseCase`, что вкладка «События» карточки, сумма = выплата на облигацию ×
    количество во всех покупках; итоги по месяцам и валютам, в рублях - по курсу на сегодня. Купон без объявленного
    размера - событие без суммы с `amountUnknown`, итоги помечены `incomplete`;
  - личная ссылка на `.ics`: `GET / POST / DELETE /portfolio/calendar/link` (одна на пользователя, в БД - SHA-256
    токена, таблица `portfolio_calendar_token`) и `GET /calendar/{token}.ics` - без `X-User-Id`, пользователь по
    токену; в файле - все будущие выплаты.
- **invest-gateway** - маршрут `/api/calendar/**` → `/internal/rest/calendar/**`, `GET`/`HEAD /api/calendar/*`
  открыт без входа (и без публичного режима); `robots.txt` закрывает `/api/calendar`.
- **invest-api-ui** - вкладка «Выплаты» на странице портфеля (`/portfolio?tab=payments`, `PortfolioPayments`):
  период (3 мес / 6 мес / год / 3 года), итог за период в рублях и по валютам, столбики сумм по месяцам, список
  событий по месяцам с суммой на облигацию и на количество, предупреждение о неполном итоге; блок «Подписка в
  календаре» - создать ссылку (адрес показывается один раз), новая ссылка, отключить. Цель аналитики
  `portfolio_calendar_link_created`.

## Готово, когда

- [x] суммы календаря совпадают с вкладкой «События» карточки × количество - `PortfolioCalendarTest.amountsMatchBondEventsTimesQuantity`;
- [x] флоатер без размера купона не занижает итог молча: событие без суммы, `amountUnknown`, итог месяца и периода
  `incomplete`, в UI - «от …» и предупреждение;
- [x] `.ics` по ссылке без сессии (`text/calendar`, RFC 5545: события на весь день, постоянный UID, перенос строк по
  75 октетов); новая ссылка отменяет прежнюю, отключённая - `404`;
- [ ] `.ics` открыт в настоящем календаре (Google / Apple / Outlook) - проверить на стенде с публичным адресом:
  Google забирает подписку со своих серверов, `localhost` ему недоступен.
