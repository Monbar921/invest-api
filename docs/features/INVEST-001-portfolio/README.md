# INVEST-001: портфель облигаций

**Статус:** в работе. Ветка `feature/INVEST-001` (invest-api), `feature/INV-001` (invest-api-ui), маршрут
`/api/portfolio/**` - в invest-gateway. Отдельной ветки нет: портфель опирается на пользователя из gateway, сделанного
для [INVEST-001-telegram-bot](../INVEST-001-telegram-bot/), и на цены облигаций.

## Цель

Пользователь ведёт свои покупки облигаций и видит, сколько они стоят сейчас и сколько он заработал или потерял
на изменении цены с момента покупки.

## Что входит

- CRUD покупок: облигация, количество, цена покупки в % от номинала, дата покупки. Одну облигацию можно купить
  несколько раз - в таблице это одна строка облигации (количество, средняя цена, суммы), покупки раскрываются под ней.
- У валютной облигации - необязательно, сколько рублей заплачено (без НКД и комиссии): тогда рублёвый доход считается
  от этой суммы, а не от курса ЦБ на дату покупки.
- Список покупок с текущей ценой, стоимостью, доходом в валюте и в % к цене покупки; доход может быть отрицательным.
- Итоги по валютам номинала: суммы в разных валютах не складываются.
- Стоимость и доход в рублях - у валютных покупок и итогов подписью под суммой в валюте. Стоимость покупки в
  рублях - по курсу ЦБ на дату покупки, текущая - по курсу на сегодня, доход в рублях - их разница (с изменением
  курса).
- Брокер у покупки (необязательно): выбор из выпадающего списка своих брокеров или новый - ввести имя и «Добавить».
  Новый брокер сохраняется и дальше есть в списке для следующих покупок, даже если покупок с ним не осталось.
- UI: страница `/portfolio`, пункт «Портфель» в шапке. Добавление - поиск облигации, цена покупки по умолчанию -
  текущая; изменение и удаление (с подтверждением) - в строке таблицы.

Решения (2026-11-08): доход - только от изменения цены, купоны, НКД, комиссии и налог не учитываются (для этого есть
калькулятор дохода); цена покупки - в % от номинала, как в калькуляторе; облигацию у покупки не поменять - только
удалить и добавить заново.

Решение (2026-11-08): брокер - метка покупки из списка пользователя; новый брокер появляется в списке, как только его
впервые указали у покупки.

Правила - в [business-rules.md](../../business-rules.md#портфель), как сделано - в [design.md](design.md).
