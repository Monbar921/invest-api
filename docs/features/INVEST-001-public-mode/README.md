# INVEST-001: публичный режим

Статус: **в работе** - сделано 2026-11-10, этап 1 [дорожной карты](../../roadmap.md). Код не закоммичен; ветки - те, на
которых сейчас репозитории: invest-gateway `test`, invest-api-ui `feature/INV-001` (отдельную ветку называет владелец).

> Включать на публичном адресе - только после решения владельца 0.1 (условия T-Invest API и ISS Мосбиржи на показ
> данных без входа). До тех пор режим выключается одной настройкой gateway
> `invest.gateway.public-access.enabled: false` - UI тогда ведёт себя как раньше: без сессии уходит на логин.

## Цель

Список облигаций, карточка, новости и калькулятор открываются без входа - по ссылке и из поиска.
Портфель и уведомления - только после входа.

## Объём

- **invest-gateway**
  - чтение `/api/bonds/**` без аутентификации: `GET`/`HEAD` и `POST .../page`, `POST .../calculation`; другие POST под
    `/api/bonds` (их пока нет) - только с сессией;
  - `/api/alerts/**`, `/api/portfolio/**` - как раньше, без сессии `401`; `X-User-Id` из браузера затирается;
  - CSRF для анонимных POST: cookie `XSRF-TOKEN` выдаётся и без сессии;
  - `GET /api/session` - состояние входа для UI (`authenticated`, `username`), всегда `200`;
  - вход с возвратом: `/oauth2/authorization/keycloak?returnTo=<путь>`;
  - ограничение частоты анонимных запросов к `/api/**` по IP (`429` + `Retry-After`).
- **invest-api-ui**: состояние «гость» - «Войти» в шапке вместо Telegram и выхода; портфель, уведомления и колокольчик
  облигации предлагают войти; после входа - возврат на ту же страницу; личные запросы гость не делает.
- **invest-api**: без изменений.
