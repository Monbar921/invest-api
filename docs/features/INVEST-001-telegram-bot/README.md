# INVEST-001: Telegram-бот с уведомлениями по облигациям

Статус: **в работе** - все четыре этапа сделаны 2026-11-08: привязка Telegram, уведомления по датам, по цене и доходности, по событиям. Ветка `feature/INVEST-001` (та же, что у доходностей,
калькулятора, графика цены и новостей).

## Цель

Пользователь отмечает облигацию кнопкой-колокольчиком в UI, выбирает правила уведомлений (цена, доходность, даты
купона, оферты, погашения, амортизации, новости) и получает сообщения в Telegram.

## Решения пользователя (2026-11-08)

- Подписка на облигацию и настройка правил - в UI (кнопка у облигации), не в боте.
- Изменение цены - оба варианта: относительно цены на момент создания правила и за день.
- В первую версию входят пороги доходности к погашению и к оферте и уведомления о дате оферты.
- Только для пользователей, вошедших через Keycloak (через invest-gateway); анонимного режима нет.
- Работа в той же ветке `feature/INVEST-001`.
- Telegram в России заблокирован, сервисы запускаются на своём ПК: запросы бота идут через локальный sing-box и свой
  VPS, остальной трафик - напрямую.

## Объём

- Бэк (invest-api): модули `alert-service` (правила, проверка, очередь уведомлений) и `telegram-bot` (long polling,
  команды, отправка через прокси); таблицы `telegram_link`, `telegram_link_token`, `bond_alert`, `notification`;
  REST `/internal/rest/alerts/**`.
- invest-gateway: пользователь из сессии Keycloak передаётся в invest-api заголовком `X-User-Id`; маршрут
  `/api/alerts/**`.
- UI (invest-api-ui): колокольчик в таблице и карточке облигации, диалог правил, страница «Мои уведомления»,
  подключение Telegram и его статус.
- Бот: `/start <токен>` (привязка), `/list`, `/stop`; в сообщениях кнопки «Отключить правило» и «Открыть в UI».

## Этапы

1. ✅ Привязка Telegram: gateway → `X-User-Id`, токен, `/start` / `/stop` / `/help`, статус и кнопка в шапке UI, прокси
   в настройках. `/list` и кнопки в сообщениях - вместе с правилами (этап 2).
2. ✅ Правила по датам (купон, частичное погашение, оферта, погашение) и очередь уведомлений; колокольчик у
   облигации, страница «Уведомления», `/list` и кнопка «Отключить это уведомление» в боте.
3. ✅ Правила по цене и доходности: уровни цены и доходности к погашению и к оферте, изменение от цены при создании и
   за день; проверка после каждого обновления цен (в торговые часы - раз в 15 минут).
4. ✅ Новости по облигации, рейтинги эмитента (АКРА, НКР), объявленный купон, решения по ключевой ставке.

## Открытые вопросы

- Решено: «изменение цены на X%» - относительные проценты (98 → 96 = −2,04%), не пункты номинала.
- Частота цен: раз в 15 минут в торговые часы (`scheduler.price`); если нужно чаще - 5 минут укладываются в лимиты
  T-Invest (один `GetLastPrices` на пачку).
- Нужен ли второй канал (email или web push), пока Telegram нестабилен в России.
