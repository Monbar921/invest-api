# INVEST-001: Реферальные ссылки брокеров

Статус: **в работе** - сделано 2026-11-11, этап 3 [дорожной карты](../../roadmap.md). Код не закоммичен; ветки - те,
на которых сейчас репозитории: invest-api `feature/INVEST-001`, invest-gateway `test`, invest-api-ui `feature/INV-001`
(отдельную ветку называет владелец).

> Партнёров в конфигурации нет (`partners: []`), поэтому блок нигде не показывается. Заполнять после решения
> владельца 0.3: договоры с партнёрскими программами, рекламодатель и erid из ЕРИР для маркировки.

## Цель

Первый доход: из карточки облигации и калькулятора пользователь переходит к брокеру-партнёру по реферальной ссылке.

## Объём

- **invest-api** - модуль `feature/broker-service`:
  - партнёры в конфигурации `ru.invest.api.broker-referral.partners`: id, название, шаблон ссылки (`{ticker}`,
    `{isin}`, `{erid}`), рекламодатель, erid, включён ли; ошибка в настройке не даёт приложению стартовать;
  - `GET /bonds/{ticker}/broker-links` - ссылки включённых партнёров для облигации;
  - `POST /bonds/{ticker}/broker-links/{partnerId}/click` - учёт перехода: счётчик за день по партнёру и облигации,
    таблица `broker_click`, без пользователя;
  - `GET /maintenance/broker-clicks?from=&to=` - переходы по дням для сверки с отчётом партнёра.
- **invest-gateway** - `POST /api/bonds/*/broker-links/*/click` открыт без входа (POST открываются поимённо, иначе клик
  гостя получал бы `401` и UI уводил бы его на логин).
- **invest-api-ui** - блок «Купить у брокера» (`BrokerLinks`) в карточке облигации под показателями и в калькуляторе
  под расчётом: кнопки партнёров, пометка «Реклама», рекламодатель и erid у каждой ссылки, «это не инвестиционная
  рекомендация»; клик отправляет учёт и открывает брокера в новой вкладке.

## Готово, когда

- [x] при пустом списке партнёров блок не показывается - тесты `noPartnersNoLinks` (invest-api) и «без партнёров
  блока нет» (UI); ошибка запроса тоже прячет блок, карточка работает;
- [x] с партнёром ссылка ведёт по шаблону, пометка видна - `linksOfEnabledPartnersByTemplateInConfigOrder`, UI-тест
  «ссылки партнёров с пометкой «Реклама», рекламодателем и erid»;
- [x] клик учитывается - `clicksAreCountedPerDayPartnerAndBond` (счётчик и maintenance-эндпоинт), UI-тест «клик по
  ссылке учитывается», gateway `brokerClickWithoutSessionIsRoutedToInvestApi`.

Не проверено на стенде k3d и в браузере с настоящим партнёром - только тестами.
