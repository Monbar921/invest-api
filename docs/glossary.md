# Глоссарий

| Термин                       | Значение                                                                                           |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| **Номинал**                  | сумма, которую эмитент возвращает за одну облигацию при погашении                                  |
| **Цена в % от номинала**     | так биржа котирует облигации: 98.5 значит 98.5% номинала                                           |
| **НКД** (ACI)                | накопленный купонный доход: часть текущего купона, набежавшая с прошлой выплаты; покупатель доплачивает его продавцу сверх цены |
| **Купон**                    | периодическая процентная выплата по облигации                                                     |
| **Фиксированный купон**      | размер всех выплат известен заранее                                                                |
| **Флоатер**                  | облигация с плавающим купоном: размер следующих выплат объявляется позже (привязан к ставке)        |
| **Купонная доходность**      | сумма купонов за год к текущей цене, без учёта НКД, погашения и времени                            |
| **Доходность к погашению** (YTM) | эффективная годовая ставка, при которой будущие выплаты (купоны, погашения) окупают цену покупки с НКД |
| **Оферта** (call/put)        | дата, когда облигацию досрочно выкупают или можно предъявить к выкупу по номиналу                 |
| **Доходность к оферте**      | YTM, если считать, что облигацию выкупят по номиналу в дату оферты                                 |
| **Амортизация**              | погашение номинала частями по графику до даты погашения                                            |
| **Погашение** (maturity)     | дата, когда эмитент возвращает остаток номинала                                                    |
| **ОФЗ**                      | облигации федерального займа - государственные облигации РФ                                       |
| **ОВОЗ**                     | облигации внешнего облигационного займа РФ                                                         |
| **Уровень риска**            | оценка T-Invest: LOW, MODERATE, HIGH                                                               |
| **uid**                      | идентификатор инструмента в T-Invest API, основной ключ облигации в системе                        |
| **ISIN**                     | международный код ценной бумаги; у российских начинается с `RU`                                    |
| **XIRR**                     | годовая ставка, при которой все вложения и выплаты с их датами в сумме дают ноль; доходность портфеля с учётом того, когда деньги вложены и получены |
| **FIFO**                     | первым пришёл - первым ушёл: продажа списывает облигации из самых ранних покупок; так считают брокер и НДФЛ |
| **Полный доход**             | доход от цены + купоны + НКД − комиссии − налог за всё время владения, с продажами и погашениями |
| **Тикер**                    | биржевой код инструмента, по нему открывается карточка облигации                                   |
